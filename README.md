# llmpolska / setup

Zestaw narzędzi, których używamy w [llmpolska](https://llmpolska.pl) do pracy z agentami AI na co dzień.
Trafiłeś tu z rolki? Super, wszystko jest poniżej. 👇

> Ceny i limity subskrypcji często się zmieniają, dlatego linkujemy do oficjalnych cenników zamiast podawać kwoty.

---

## 🧠 Centrum dowodzenia

| Narzędzie | Co to jest | Link |
|---|---|---|
| **T3 Code** | Jedno okno do sterowania Claude Code, Codexem, OpenCode i Cursorem z komputera albo telefonu. Kilku agentów obok siebie, wątki, worktree. | [t3.codes](https://t3.codes) · [GitHub](https://github.com/pingdotgg/t3code) |
| **T3 Stack** | Nasz domyślny start nowego projektu: Next.js, TypeScript, tRPC, Tailwind, Drizzle/Prisma i Auth.js. | [create.t3.gg](https://create.t3.gg) · [GitHub](https://github.com/t3-oss/create-t3-app) |

## 🤖 Agenci do kodowania

| Narzędzie | Co to jest | Link |
|---|---|---|
| **Claude Code** | Agent od Anthropic, nasz główny koń roboczy. | [claude.com/claude-code](https://claude.com/claude-code) |
| **Codex CLI** | Agent od OpenAI, działa w terminalu. | [GitHub](https://github.com/openai/codex) |
| **OpenCode** | Open-source'owy agent, który działa z dowolnym modelem. | [opencode.ai](https://opencode.ai) · [GitHub](https://github.com/anomalyco/opencode) |
| **Mistral Vibe** | Minimalistyczny agent CLI od Mistrala. | [mistral.ai/products/vibe](https://mistral.ai/products/vibe) · [GitHub](https://github.com/mistralai/mistral-vibe) |
| **Cursor CLI** | Agent Cursora w terminalu. | [cursor.com/cli](https://cursor.com/cli) |

## 🔌 Klej i dodatki

| Narzędzie | Co to jest | Link |
|---|---|---|
| **opencodex** | Proxy, które pozwala podpiąć dowolny model (Claude, Gemini, Grok, DeepSeek, Ollama…) pod Codexa i Claude Code. | [opencodex.me](https://opencodex.me) · [GitHub](https://github.com/lidge-jun/opencodex) |
| **gflow-cli** | Google Flow z terminala: wideo Veo i obrazy Imagen, z serwerem MCP dla agentów. Robimy tym materiały do rolek. Nieoficjalne, alpha. | [Docs](https://ffroliva.github.io/gflow-cli/) · [GitHub](https://github.com/ffroliva/gflow-cli) |

## 💸 Subskrypcje, które według nas najbardziej się opłacają

Zamiast płacić za API od tokena, bierzemy stałe subskrypcje i podpinamy je pod agentów (np. przez T3 Code).

| Subskrypcja | Dlaczego | Cennik |
|---|---|---|
| **Anthropic (Claude Pro / Max)** | Najlepszy agent do kodowania. Plan Max ma sens, jeśli Claude Code chodzi u ciebie cały dzień. | [claude.com/pricing](https://claude.com/pricing) · [API](https://platform.claude.com/docs/en/about-claude/pricing) |
| **OpenCode (Zen / Go)** | Tani dostęp do wielu modeli w jednym miejscu, bez kombinowania z kluczami. | [Zen](https://opencode.ai/zen) · [Go](https://opencode.ai/go) |
| **Mistral (Le Chat Pro)** | Europejski dostawca, bardzo dobry stosunek ceny do możliwości, w pakiecie Vibe. | [mistral.ai/pricing](https://mistral.ai/pricing) |
| **ChatGPT (Plus / Pro)** | W pakiecie Codex, przydaje się jako drugi agent do review. | [chatgpt.com/pricing](https://chatgpt.com/pricing) |
